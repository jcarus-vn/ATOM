# Security notice - install ATOM only from its official repository

The only official ATOM repository is:

> **https://github.com/jcarus-vn/ATOM**

Do not install or run copies of ATOM (or of the converter it is based on)
from other accounts or re-uploads: they are not affiliated with, maintained
by, or endorsed by this project, and their code may differ from what is
reviewed here.

## Verify before installing

Use only the official repository and installation source:

```bash
npx skills add jcarus-vn/ATOM
```

or:

```bash
git clone https://github.com/jcarus-vn/ATOM.git
```

If you find a suspicious copy, report it in ATOM's issue tracker with the
URL and what differs.
